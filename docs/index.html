📖 O que é o Idle Labs?

🧠

Conceito

O Idle Labs é um aplicativo desktop baseado em Electron que transforma seu navegador em um gerenciador de sessões múltiplas. Ele permite criar workspaces (ex: "Principal", "Trabalho", "Pessoal") e, dentro de cada um, adicionar quantas contas desejar — cada uma com cookies, cache e logins totalmente isolados.

Ideal para quem gerencia múltiplos perfis em jogos, redes sociais, e‑commerce ou qualquer serviço que exija login único por sessão.

🎯

Para quem é?

  • Jogadores que querem rodar várias contas de MMORPG (ex: Pokémon Idle)
  • Gestores que administram várias redes sociais
  • Testers que precisam testar fluxos com diferentes perfis
  • Desenvolvedores que precisam simular múltiplos usuários

✨ Funcionalidades e Módulos

📂

Workspaces

Organize suas contas em categorias visuais com ícones, cores e layouts personalizados. Crie, duplique, renomeie e reordene via drag‑and‑drop.

👤

Contas Isoladas

Cada conta roda em uma partição separada do Electron. Cookies, cache, localStorage e sessões são totalmente independentes.

🧩

Layouts Flexíveis

Escolha entre grade automática, painel único, colunas, linhas ou livre para organizar os painéis de cada workspace.

🔄

Recarregamento em Segundo Plano

Troque entre workspaces sem perder o estado das contas — tudo permanece em memória e continua rodando em background.

🔇

Controle de Áudio

Silencie painéis individuais ou todos de uma vez. Ideal para evitar sons indesejados de várias sessões abertas.

📊

Métricas em Tempo Real

Acompanhe CPU, RAM e FPS de cada conta e do processo principal na barra de status.

🔍

Barra de URL Universal

Digite uma URL e ela será aberta em todas as contas abertas do workspace atual com um clique.

💾

Persistência Local

Tudo é salvo automaticamente em state.json. Ao reabrir, o aplicativo restaura exatamente onde você parou.

🌐

Export/Import

Exporte toda a configuração de workspaces e contas para um arquivo .json e importe em outra máquina.

📥 Como Instalar e Executar

Passo 1: Clonar o repositório

git clone https://github.com/Diinhow/Idle-Labs.git
        cd Idle-Labs

Passo 2: Instalar dependências

npm install

Passo 3: Rodar em desenvolvimento

npm start

Passo 4: Gerar instalador

npm run dist

Gera .exe (Windows), .dmg (macOS) ou .AppImage (Linux) na pasta dist/.

⚙️ Stack Tecnológica

⚛️

Electron

Framework para aplicações desktop com JavaScript, HTML e CSS. Versão 31.0.0.

🖥️

Vanilla JS

Todo o frontend é JavaScript puro, sem frameworks — performance máxima e fácil auditoria.

🎨

CSS Custom

Estilização própria com variáveis CSS, sem dependências externas. Tema escuro nativo.

📦

electron-store

Persistência simples e segura de configurações e estado do aplicativo.

🔌

IPC Seguro

Comunicação entre processos com contextBridge e preload.js para isolar o renderer.

🛠️

electron-builder

Empacotamento e distribuição multiplataforma com assinatura automática.

🛡️

Segurança & Transparência

Código aberto e auditável.

Todo o processamento é feito 100% no seu computador. Nenhuma senha, token ou dado é enviado para servidores externos.

🔍 Código Aberto

O repositório é totalmente público no GitHub. Qualquer pessoa pode auditar, contribuir ou modificar.
